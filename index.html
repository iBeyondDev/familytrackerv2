Set up the sheet

Ten minutes, once. After that it just runs.

  1. Make a new Google Sheet and name it something like Consistency Tracker.
  2. In that sheet open Extensions → Apps Script.
  3. Delete whatever is in the editor, then paste the code below (use the copy button).
  4. On line 1, change change-me to a passphrase of your own, and type the same passphrase in the box above.
  5. Press Deploy → New deployment. Choose type Web app. Set Execute as: Me and Who has access: Anyone. Deploy, allow the permissions Google asks for, and copy the web app URL.
  6. Paste that URL above and press Connect and sync. Your Data tab fills in, and a readable tab appears for each month.

      
Anyone who has both the link and the passphrase can write to the sheet, so share them only with the four of you. To change the passphrase later, edit the script, deploy a new version, and update the box above.

    


    

      
If Google blocks the authorization

      
Look at which screen you actually got — they need different fixes.

      
    
        
  1. "Google hasn't verified this app" — this is the normal one for a script you wrote yourself. Click Advanced, then Go to … (unsafe), then Allow. It says unsafe because nobody has reviewed it; the code is yours.
    2. 
        
  2. "This app is blocked" with no Advanced link — your account's policy is refusing it. Work through these:
          
      
            
    • Keep the @OnlyCurrentDoc line at the top of the script. It limits access to this one sheet, which is a non-sensitive permission and often clears the block.
      • 
            
    • Sign out of every Google account except the one that owns the sheet, or do the setup in a private window. Multiple signed-in accounts is the most common cause.
      • 
            
    • School or work account? Its administrator blocks unverified scripts. Move the sheet to a personal Gmail account and set it up there.
      • 
            
    • Advanced Protection Program turned on? It blocks all scripts. Turn it off, authorize, turn it back on.
      • 
            
    • Account managed by Family Link or under 18? It will stay blocked. Use an adult's account as the owner.
      • 
          
    
        
    3. 
        
  3. Only the sheet owner ever authorizes anything. The other three just open the page — they're never asked to sign in.

Hosting

      
The file is self-contained, so any static host works.

      
    
        
  1. Drop this HTML file into a GitHub Pages repo, or drag it onto netlify.com/drop, or put it in a shared Google Drive folder and open it from there.
    2. 
        
  2. Send the four of you the page link. Each person opens it once, pastes the same web app link and passphrase, and picks their name.
    3. 
        
  3. From then on, whoever logs hours updates the sheet, and everyone else sees it within 15 seconds.

Defaults follow your rule: 4 or more is consistent, 1 up to 4 is partial, under 1 is a miss.
